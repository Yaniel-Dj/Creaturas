🐉 Editor de Criaturas

Genera el SQL completo para crear una criatura. Organizado en pestañas (una por tabla). Al rellenar un CreatureDisplayID, se generan automáticamente las filas en creature_template_model y creature_model_info.

Las 3 tablas imprescindibles para que un NPC funcione: creature_template + creature_template_model + creature_model_info. Las tablas opcionales (Addon, Equip, Spells, Resistance, Movement) solo se incluyen si les das un valor distinto de 0.
🎯 Tipo de criatura — pre-rellena campos automáticamente
